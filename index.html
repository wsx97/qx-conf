Quantumult X 懒人配置

复制下面的地址，粘到 Quantumult X 里即可导入整份配置（分流 + 重写 + 策略组 + DNS）。

  1. 点上面的按钮复制地址
  2. QX → 配置文件 → 右上角「+」→ 添加远程配置 → 粘贴 → 确认
  3. QX → 服务器 → 添加你自己的机场订阅（订阅不在本仓库里，需自备）
  4. 回首页把策略组切到「黑白名单」或对应地区组，打开开关

为什么订阅要单独加：配置里的 [server_remote] 只留了占位注释，把私人订阅写进公开仓库既会泄露、也会在更新时被覆盖。 QX「服务器」页添加的节点会自动进入 [policy] 的地区策略组（靠节点名里的 港/HK、台/TW、日/JP、坡/SG、美/US 等关键词匹配）。
