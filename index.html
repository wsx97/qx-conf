Quantumult X 配置

两个版本，各自单独导入，别同时启用。复制地址后到 QX →「配置文件」→ 右上角「+」→ 添加远程配置。

完整版

约 5.9 万条规则 / 5 个重写模块 / 12 策略组。覆盖面最大，冷启动几秒。

极致精简版

约 1.07 万条规则（−82%）/ 2 个重写模块 / 4 策略组 / 零解析器依赖。启动快、误伤少，广告拦截约 60–70%。

  1. 复制对应版本的地址
  2. QX → 配置文件 → 右上角「+」→ 添加远程配置 → 粘贴 → 确认
  3. QX → 服务器 → 添加你自己的机场订阅（订阅不在本仓库，需自备）
  4. 回首页把策略组切到「黑白名单」或对应地区组，打开开关
